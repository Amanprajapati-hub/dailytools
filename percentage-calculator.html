What Is a Percentage Calculator?

A percentage calculator is an online math tool that helps you calculate how numbers relate to one another using percentages. A percentage represents a part of a whole based on 100 and is written using the % symbol.

This Percentage Calculator provides three common types of calculations. You can find a percentage of a number, determine what percentage one number is of another and calculate the percentage increase or decrease between two values.

Percentage calculations are useful for shopping discounts, exam results, price comparisons, budgeting and many other everyday situations.

Percentage Formulas Explained

The calculator performs the mathematical calculations automatically, but understanding the basic formulas can also help you check a result manually.

1. Finding a Percentage of a Number

Formula:

Percentage Result = (Percentage ÷ 100) × Number

Example: What is 20% of 500?

(20 ÷ 100) × 500 = 100

Answer: 100

2. Finding What Percentage One Number Is of Another

Formula:

Percentage = (First Number ÷ Second Number) × 100

Example: What percentage is 25 of 200?

(25 ÷ 200) × 100 = 12.5%

Answer: 12.5%

3. Calculating Percentage Increase or Decrease

Formula:

Percentage Change = ((New Value - Original Value) ÷ |Original Value|) × 100

Example: A value changes from 400 to 500.

((500 - 400) ÷ 400) × 100 = 25%

Answer: 25% increase.

Tips for Accurate Percentage Calculations

  • Identify the correct original or reference number before starting a calculation.
  • Remember that percentage change is normally measured relative to the original value.
  • Check whether you need a percentage amount, a percentage comparison or a percentage change.
  • Do not use zero as the reference number when the calculation requires division.
  • Review your entered values before calculating, especially when working with large or decimal numbers.

Frequently Asked Questions

1. What is a percentage?

A percentage is a way of expressing a number as a fraction of 100. It is represented using the % symbol.

2. Is the DailyTools Percentage Calculator free?

Yes. You can use this Percentage Calculator without creating an account or paying a usage fee.

3. How do I calculate 20% of a number?

Divide 20 by 100 and multiply the result by your number. For example, 20% of 500 is 100.

4. How do I find what percentage one number is of another?

Divide the first number by the reference number and multiply the result by 100.

5. How is percentage increase calculated?

Subtract the original value from the new value, divide the difference by the original value and multiply by 100.

6. Can a percentage be greater than 100%?

Yes. A percentage greater than 100% means the amount is larger than the reference value. For example, 150% of 200 is 300.

7. Can I use decimal numbers?

Yes. The calculator accepts both whole numbers and decimal values.

8. Why cannot the reference number be zero?

Division by zero is mathematically undefined, so a zero reference number cannot be used for calculations that require division.

9. Does the calculator work on mobile devices?

Yes. The responsive layout is designed to work on smartphones, tablets and desktop computers.

10. Do I need to install anything to use this tool?
